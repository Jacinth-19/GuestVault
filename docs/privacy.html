Privacy Policy

Borrow my phone. Keep your privacy.

1The short version

GuestVault is a local app. It has no account, no cloud, no analytics and no advertising, and it does not request the Android INTERNET permission — so it is technically incapable of sending your data anywhere, even if it wanted to. Everything it stores stays in this app's private storage on your phone, and uninstalling GuestVault deletes all of it.

2What GuestVault stores — and why

DataWhyWhere
Owner settings Allow-list, auto-wipe choice, session timer, theme and lock preferences. App-private DataStore file
PIN verifier A salted PBKDF2 hash of your 4-digit PIN. The PIN itself is never written to disk. Android encrypted preferences (AES-256)
Unlock attempt counter Makes sure the 5-attempt limit and cool-down survive a restart, so a guest cannot reset them. App-private DataStore file
Session history Start time, end time, number of allowed apps and how a session ended. Last 50 sessions. App-private DataStore file
Guest scratch folder Created when a session starts and emptied on exit, so no guest leftovers remain. App-private files directory

Not stored, ever: what the guest did, which apps the guest opened, keystrokes, screenshots, location, contacts, messages, or any device identifier.

4What GuestVault can and cannot clear after a session

With “auto-wipe” on, GuestVault empties its own cache, its guest scratch folder and any WebView/code-cache it owns. A normal Android app cannot erase other apps' data (their messages, browser history or photo caches) — Android reserves that for the device-owner role, which GuestVault deliberately does not request. Browsing inside an allowed browser is still that browser's data. The app says so in Settings → How GuestVault works instead of pretending otherwise.

5Children

GuestVault is a tool for adults lending their own phone. It is not directed at children, collects no data from anyone, and contains no ads or purchases.

6Your control and data deletion

  • Delete everything: uninstall GuestVault, or clear its storage in Android Settings → Apps → GuestVault → Storage. This removes settings, the PIN hash, the attempt counter and all session history instantly.
  • Delete history only: Settings → Session history → Clear history.
  • Revoke a permission: Android Settings → Apps → GuestVault → Permissions. The PIN always remains a working way out.
  • No data request is needed: because no data ever leaves the device, there is nothing for the developer to look up, export or delete on your behalf.

7Changes and contact

Material changes to this policy will be published on this page and noted in the app's release notes before they take effect. Questions or security reports are welcome through the project's issue tracker: github.com/Jacinth-19/GuestVault/issues.
