# Asset licences

Everything GuestVault ships is either written for this repository or comes from a
dependency under a permissive licence. No image, animation or font in the app is
scraped from an app store, a stock site or another product.

## Images and animations

| Asset | Where | Origin | Licence |
| --- | --- | --- | --- |
| `res/raw/lend_hand.json` | onboarding page 1 | Generated by `scripts/assets/build_lottie.py` | MIT (this repository) |
| `res/raw/app_grid.json` | onboarding page 2 | Generated by `scripts/assets/build_lottie.py` | MIT (this repository) |
| `res/raw/shield_key.json` | onboarding page 3 | Generated by `scripts/assets/build_lottie.py` | MIT (this repository) |

| `res/drawable/ic_status_*.xml` | notification small icons | Hand-authored vectors | MIT |
| `res/drawable/ic_launcher_foreground.xml`, `res/mipmap-*/` | launcher icon | Hand-authored vector, rendered by the Android build | MIT |
| `docs/media/*.png`, `docs/media/walkthrough.mp4` | README, Play listing | Screenshots of this app, captured by CI | CC0 (project waives rights) |
| `docs/media/logo.svg` | README header | Hand-authored | MIT |

**Why the animations are generated.** Lottie marketplaces mix CC0, MIT,
"free for personal use" and no-licence files, and a hand-drawn animation from an
unknown source is exactly the kind of asset that turns into a Play Store takedown
or a licensing claim later. `build_lottie.py` emits the JSON from primitives
(rounded rectangles, ellipses, one polygon shield), so authorship is unambiguous
and the geometry is reviewable in a diff.

Regenerate and validate:

```bash
python3 scripts/assets/build_lottie.py          # write
python3 scripts/assets/build_lottie.py --check  # fail if out of date
python3 scripts/ci/check_lottie.py              # structure, budget, drift
python3 scripts/assets/preview_lottie.py        # PNG contact sheet (needs Pillow)
```

`scripts/ci/check_lottie.py` runs in Android CI. It enforces a **100 KB budget**
per file, valid keyframe ordering, colours in `0..1`, and a shape allow-list
(`gr`, `rc`, `el`, `sh`, `fl`, `st`, `tr`, `tm`), so nobody can smuggle in an
unsupported construct that renders as a blank page on a device.

## Fonts

The app uses the platform default (`Roboto` on Android) through Compose
`Typography`. No custom font files are bundled, so there is no font licence to
track and no extra download size.

The full dependency tree is pinned in `gradle/libs.versions.toml`. Apache 2.0
requires attribution, which the About screen provides via the MIT/Apache notice
in `core/LegalText.kt`; no licence text needs to be shipped as a separate file
for a non-distributed internal build, and the Play listing links the privacy
policy.

## What is deliberately *not* used

- **No stock illustrations.** The previous onboarding art was a Material icon in
  a gradient circle — also generated, but it read as a placeholder.
- **No scraped Lottie files.** Not from LottieFiles, not from a "free UI kit",
  not from another app's assets.
- **No emoji or web fonts.** Both have unclear redistribution terms at the app
  level.
- **No AI-generated imagery in the shipping app.** Every pixel in the APK is
  either a hand-authored vector or vector geometry emitted by the generator,
  which keeps the provenance auditable.

If an external asset is ever added, record it in the table above with its exact
source URL and licence before merging the PR — a missing row is treated as a
release blocker.
